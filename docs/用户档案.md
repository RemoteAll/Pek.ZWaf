## 本项目相关口径

- 中文交流；「直接推进 + 关键处确认」。
- **功能对齐参考实现，不自行发明**：行为以 Rust `Pek.RWaf` 为准、规则格式以 C# `Pek.WAF` 为准；
  任何差异必须写进 `docs/设计说明.md` §4，不允许静默降级。
- **复用优先**：先 `zzig` → 兄弟项目 → 本仓库；不复用公共库要在注释里写「为什么」并留检索证据。
- **验证分档**：自测 = `zig build test` + `zig build`（必要时 `zig build demo` 起实例实测）；
  `--release` / 交叉编译只在用户明确说「打包 / 出包 / 部署」时才做。
- 每轮收尾必须：决策记录（含原话）+ 记忆同步 + 回归实测输出，缺一不可。

## 已知约束（用户口径）

- 生态公共库是 `G:\Code\Zig\zzig`（Zig 侧对齐 Rust `dhrust`）——通用能力一律下沉/复用，不做第二份实现。
- Zig 版本 0.17.x；0.17 的 API 变动（Mutex/时间/文件 IO/bytesToHex/`**`）按 `docs/设计说明.md` §6 处理。
- 面向面板的可观测性要**一眼可见**：统计快照（拦截数/拦截率/近 1 分钟/按原因/Top IP）直接给前端消费，
  不做「让运维翻日志」的设计。
- 安全默认从严（`adminApi()` 预设），前台站点用 `publicSite()`；危险动作（升级/删除/覆盖）语义不能丢。
