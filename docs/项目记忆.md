### 已踩的坑（改代码前先看）

- `zzig.Net.parseCidr` 在 `/0` 上 `@intCast` panic → `wafreq.zig` 自写容错解析（zzig 修复后可切回）。
- `std.json` 字符串别名输入文本 → 解析文本必须分配在 **arena**，用 gpa 释放会让规则名变 0x55 乱码。
- `zzig.config.toml.decode` 从类型默认值起步 → 会清空调用方预设，改用「逐键覆盖」。
- 路由中间件只覆盖已匹配路由 → `/.env` 早拒必须用 `ServerGuard`；`http_server` 视图无对端地址 → IP 未知时不做 CC。
- `Ctx.req.headers` 不可变 → 限流放行状态写 `ctx.state`；被拦响应用静态 Header 数组（栈上会悬空）。
- Zig 0.17：无 `std.Thread.Mutex`（用 `zzig.compat.Mutex`）、无 `std.time.timestamp`（用 `zzig.compat.nanoTimestamp`）、
  文件 IO 要 `Io`、无 `ArrayList.writer`（用 `print(gpa,…)`）、无 `fmtSliceHexLower`（用 `bytesToHex`）、字符串不能用 `**`。
