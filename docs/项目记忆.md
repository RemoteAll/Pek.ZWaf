### 已踩的坑（改代码前先看）

- `zzig.Net.parseCidr` 在 `/0` 上 `@intCast` panic → `wafreq.zig` 自写容错解析（zzig 修复后可切回）。
- `std.json` 字符串别名输入文本 → 解析文本必须分配在 **arena**，用 gpa 释放会让规则名变 0x55 乱码。
- `zzig.config.toml.decode` 从类型默认值起步 → 会清空调用方预设，改用「逐键覆盖」。
- 路由中间件只覆盖已匹配路由 → `/.env` 早拒必须用 `ServerGuard`；`http_server` 视图无对端地址 → IP 未知时不做 CC。
- `Ctx.req.headers` 不可变 → 限流放行状态写 `ctx.state`；被拦响应用静态 Header 数组（栈上会悬空）。
- Zig 0.17：无 `std.Thread.Mutex`（用 `zzig.compat.Mutex`）、无 `std.time.timestamp`（用 `zzig.compat.nanoTimestamp`）、
  文件 IO 要 `Io`、无 `ArrayList.writer`（用 `print(gpa,…)`）、无 `fmtSliceHexLower`（用 `bytesToHex`）、字符串不能用 `**`。

### 100 万口径性能与限流（2026-11-18）

- 特征共 **82 条**（SQLi 30 / XSS 13 / 路径 28 / 命令 11）；改造前是同一段文本被 82 个 `indexOf` 各扫一遍。
- 改造：`attack.ScanIndex`（首字节桶 + 第二字节过滤的单遍扫描）、缓冲一次预留、`wafreq.IpSet`
  （IP 名单预编译：`/32`→u32 哈希、CIDR 预解析）、`rules.Op/Member` enum 化；动作 `off` 的类别不扫描。
- 实测（ReleaseFast，100 万次）：放行 GET **6826.8 → 365.6 ns**；SQLi **3990.9 → 510.5 ns**；
  静态资源 **1429.6 → 272.0 ns**；8KB body 从跑不完 → **23.98 µs**；100 万条 IP 名单 miss **204.5 ns**；
  1000 条规则 miss **3.20 µs**。构建 100 万条 IP 名单一次性约 **1439 ms**。
- 复用的 zzig：`Strings.containsIgnoreCase`（收编 wafreq/bots 两份自写）、`hash.constantTimeEql`。
- 限流两套：CC（`rateLimitPerMin`，`WindowLimiter`，每 IP 60s 窗口）+ 接口级 `throttle.zig`
  （`Config/Throttle.json`，7 策略 / 多阀门 / 429 三格式 / `middleware()` 或 `guard()`）。单测覆盖。
- **关键缺口**：`zzig.http_server.RequestView` 无对端地址、`web.App.serverHandler` 不填 `remote_addr`
  → 走 App 接入时 `ip==""`：CC 不计数、IpSet 名单不命中、throttle 的 ip 策略失效。
  实测 demo 连续 12 次全 200、日志 `IP=` 为空；直接传 `remote_addr` 时 CC=10/min 得 `200×10 → 429×2`。
  修复点：zzig `RequestView` + `serverHandler`（当日已完成，见下）。
- 第一轮后再做：**Stage 有界对象池**（复用 349.1ns vs 每请求新建 3257.6ns，9.3×）、
  **限流器分片锁**（16 片，8 线程 23.3ns/次 ≈ 4286 万次/秒）、**早拒统计修复**
  （早拒拦截补记 `recordRequest`，原来 ratio 会 >1，demo 实测 1.5；现 0.5）。
- **缺口已修复（2026-11-18）**：zzig `RequestView` 新增 `remote_addr`（accept 的 socket 地址，
  格式 `ip:port`），`serveOne` 填充、`web.serverHandler` 透传；demo 实测 12 次 → `200×10 → 429×2`，
  日志 `IP=127.0.0.1`；zzig 回归 225/225。
- **Zig 0.17 格式化坑**：`IpAddress` 只实现新 `Io.Writer` 接口，`std.fmt.bufPrint("{}")` 不报错、
  静默输出结构体调试格式；必须 `var w: std.Io.Writer = .fixed(&buf); addr.format(&w); w.buffered()`。
