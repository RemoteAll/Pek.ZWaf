## 1. 项目速览

- 名称：`Pek.ZWaf`；目录 `G:\Code\Zig\Pek.ZWaf`；远端 `https://github.com/RemoteAll/Pek.ZWaf.git`（`origin/main`）。
- 定位：**Zig 版 WAF 公共库**，功能对齐 Rust `Pek.RWaf`、规则格式对齐 C# `Pek.WAF`，
  以 `zzig` 中间件形态接入任意 Zig HTTP 服务。
- 工具链：Zig 0.17.0 / 0.17.1（两条路径都验证过）；path 依赖 `G:\Code\Zig\zzig`。
- 当前能力：爬虫分级（6 类）· 攻击特征（SQLi/XSS/路径/命令）· CSRF · IP 名单（精确/CIDR/通配符/文件）·
  CC 限速 · 接口级限流（7 策略）· C# 兼容规则引擎 · 热重载 · 运行统计 · HTTP 层早拒 · 可信签名放行。
- 明确边界：`http_server.RequestView` 不带对端地址 → 早拒层不做 IP/CC；IP 未知时不做 CC 计数。
  路由中间件不覆盖未匹配路径 → 路径探测定向 `ServerGuard`。

```powershell

# 演示验证（浏览器 UA 必须显式给：curl 默认 UA 本身在恶意名单里）

curl.exe -s -o NUL -w "%{http_code}" -A "sqlmap/1.7" http://127.0.0.1:18080/ping                    # 403
curl.exe -s -o NUL -w "%{http_code}" http://127.0.0.1:18080/.env                                    # 403（早拒）

# 接续基建
powershell -NoProfile -ExecutionPolicy Bypass -File tools/continuity/install-global-instruction.ps1  # 用户级指令自检（幂等）
```

## 4. 常见任务

| 任务 | 做法 |
| --- | --- |
| 接一个新 Zig 服务 | `Waf.load(gpa, io, base)` → `app.useMiddleware(waf.middleware())` → 可选 `ServerGuard` 包 `http_server.Server.handler` |
| 机器对机器 API 被脚本 UA 误拦 | 配置 `skipBotPrefixes = ["/api"]` 或 `waf.setForcedSkipBotPrefixes(&.{"/api"})`；已在用 HMAC 签名的项目用 `setTrustedSecret` |
| 管理端点本体就要执行 SQL / 传文件 | `skipAttackPrefixes`（只跳过攻击检测，bot/IP/CC 仍生效） |
| 新增攻击特征 | `src/attack.zig` 对应名单 + 用例；注意规范化口径（折叠空白 + ASCII 小写 + 双重解码） |
| 新增爬虫名单 | `src/bots.zig` 对应表；分类顺序固定（malicious → search → ai → social → monitor → unknown） |
| 新增规则操作符 | `src/rules.zig` 的 `evalLeaf`/`evalExt` + 用例；保持 C# 兼容（未知操作符**不命中**，宽容） |
| 调限流 | `Config/Throttle.json`（规则→阀门两层数组）；`whenNull=intercept` 按客户端 IP 计数 |
| 看是否被攻击 | `waf.snapshot()`：`total/blocked/blocked_ratio/last_minute/last_5_minutes/reasons/top_ips` |

## 5. 已知坑（都实测过）

1. **zig `parseCidr` 在 `/0` 上 panic**（`u5` 装不下 32）→ 本项目自写容错解析；zzig 修复后可切回。
2. **`std.json` 字符串别名输入文本** → 解析文本必须分配在 arena，否则规则名变 0x55 乱码。
3. **`toml.decode` 从类型默认值起步** → 会清掉调用方预设；本项目改为逐键覆盖。
4. **路由中间件不覆盖未匹配路径** → 早拒必须挂 `ServerGuard`，否则 `/.env` 只得到 404。
5. **Ctx.req.headers 不可变** → 限流「放行」状态写 `ctx.state`（`Api-Throttle-Status=1`），不写请求头。
6. **`Response.headers` 生命周期** → 被拦响应用**静态** Header 数组，不用栈上临时数组。
